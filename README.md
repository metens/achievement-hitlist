# Achievement Hitlist

Turn goals into achievements.

## MVP

Achievement Hitlist uses AI to turn natural-language goals into 5–7 progressively harder milestones. Users complete milestones, earn XP, level up, and unlock a Final Boss.

Progress is currently stored locally in the browser. The OpenAI API key is server-side only through the `OPENAI_API_KEY` environment variable on Vercel.
